HRPAuth WebUI 是使用 React/MUI 构建的账号门户，面向自托管 HA 部署的用户。

它将登录、账号安全与皮肤管理，同 HRPAuth 托管的 SDK 包注入的生态页面汇集在一起。

## 为什么选择 HRPAuth WebUI

- **安心登录。** 在同一个门户中使用 HRPAuth 账号登录与注册。
- **掌控账号安全。** 管理第二因素与安全设置。
- **打造个性档案。** 通过已连接的 HASkinLib 服务管理皮肤。
- **自然切换语言。** 使用英文与简体中文界面。
- **承载生态工具。** 展示由 HRPAuth 托管 SDK 包提供的服务页面。
